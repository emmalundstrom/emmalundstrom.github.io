THE PROJECT

Five seasons.
Two numbers.
One story.

How has Arsenal's performance changed across five Premier League seasons?

This visualization compares goals scored and goals conceded to explore how the balance between attack and defence has developed over time.

By placing the two metrics side by side, the data makes it easier to see how Arsenal's attacking output and defensive performance have changed from season to season.
